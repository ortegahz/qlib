## 一句话口径

**把「训练目标 / 输入特征 / 数据口径 / 评估口径」与「月频实盘执行」对齐到同一个
20 交易日尺度上**，并且**不许**用测试集调参。

🔴 **2026-11-17 夜班口径变更**：**调仓节奏 cadence（`rebalance_every_n_days`）已进
val 段搜索空间**（候选 `{20, 40, 60, 90}`）—— 原因：用户红线「换手 16.57× → **≤4×**」
在 cadence = 20 的折叠常量下**不可达**（val 实测最低 **12.32×**，结构性来源 =
「持仓跌破 MA ⇒ 无条件卖出」）。⇒ **cadence ≠ 20 时，换手与 V1 的 16.57× 不是同一口径，
不可直接对比**；**cadence = 20 也只是「节奏」相同，换手权重基准仍不同源 ⇒ 只趋势性对比**。
🔴 **结构性张力（必须披露）**：val 段只有 ≈2 年（46 个信号日）⇒ cadence 20/40/60/90 ⇒
调仓次数 **23 / 12 / 8 / 6** ⇒ **「≤4×」与「val 段样本充足（`CADENCE_MIN_REBALANCES = 12`）」
在 2 年窗口下不可兼得** ⇒ 选参照旧（不改口径），但 `n_rebalances` / 样本充足性
必须写进选参闸门输出、冻结产物与成绩单，最终判据交给**盲测段（2024–2026）**。

## 一条时间线红线（**硬隔离**）

- **embargo 为什么是 25 而不是 20**：标签窗口末端 = t+25 ⇒ 只裁 20 天时，训练末样本的
  标签窗口会伸到 2022-01-10 ⇒ 与验证段**重叠 6 个交易日** ⇒ 结构性泄露。
  取 `max(20, 25) = 25`（仍满足「≤ 2021-12-31 前第 20 个交易日」这条上界）。
  ⇒ `splits.assert_no_label_overlap` 是**会真报红**的硬断言（字面 20 天口径 ⇒ 抛错）。

### 实测结果（2026-11-18 跑批；OOS = 2019–2023 五折拼接，**0 折作废**）

最优：**``pure_E_native`` + hold_buffer=2 + 负分闸门 off**（cadence=20 / top_k=5 焊死）

| 指标 | 5 折 OOS（2019–2023） | 旧 V2 基线（``v2_frozen_ma120_80`` b=2） |
| --- | --- | --- |
| 年化收益 | **13.51%** | 5.87% |
| 最大回撤 | **−32.29%** | −46.60% |
| 年化超额（几何，扣费后） | **+7.39%** | +0.16% |
| 年化换手（单边） | 14.10× | 12.73× |
| 成本拖累 | 4.43% | — |
| ETF 层 20 日 RankIC | 0.0488（t=0.795 / 54 截面） | 0.0293 |

分折（年化 / 回撤 / 年化换手）：2019 **+39.02%** / −14.84% / 6.10×；
2020 **+65.31%** / −16.90% / 13.67×；2021 −8.14% / −28.55% / 12.81×；
2022 +11.09% / −18.64% / 18.21×；2023 −19.87% / −22.86% / 19.73×。

🔴 三条**跨周期**结论（5 折 OOS 比 2 年熊市 val 段可信得多）：

1. **动量项确实在吃 Alpha**（用户归因文档的结论被独立验证）：
   ``E_mom_native``（alpha 0.5 + 动量 0.5）超额 **−0.84% ~ +1.79%**、回撤 −49%~−53%
   ⇒ 远差于纯 E（+7.39%）。
2. **负分空仓闸门在 5 折上**是**净负贡献**（同一方案/缓冲带：+3.21% vs +7.39%）
   ⇒ 它是为「单边熊市 val 段」设计的，跨周期反而砍掉了上涨年的收益。
3. **同族上限**略负（+5.23% vs +7.39%）⇒ 纯 E + top-5 等权更优。

🔴 换手 14.10× 仍**远高于 ≤4× 红线**（cadence=20 下的**结构性**结果，不是没搜到）；
ETF 层 RankIC 仅 0.0488（t=0.795）⇒ **ETF 层排序信号偏弱**，超额更多来自
「纯 E + 等权 + 月频」的组合结构，而非强个股信号的直接兑现 ⇒ 这一点必须写进结论。

## 🔴 已知局限（如实披露，不掩盖）

1. **历史真实成分股/权重不可得**：akshare `fund_etf_holdings_tx` / `fund_etf_pcf`
   都不提供历史 PCF ⇒ 回测用 2026-11-04 快照倒推历史（V1 同款结构性问题）。
2. **ETF 逐日停牌数据本地缺失** ⇒ 停牌标记用「**零成交**」近似；
   🔴 **涨跌停用「日涨跌幅 ≥/≤ 9.5%」近似**（`config_v2.LIMIT_THRESHOLD`）⇒
   ① 对 ±20% 涨跌停品种（跨境 / 商品 ETF）判不出板（**偏保守**地把正常票当成不可买）；
   ② 真实判板应看「收盘价 == 涨跌停价」，本项目未取到涨跌停价字段。
   ✅ **ETF 层真实流动性约束已接入**（`run_v2.build_etf_tradable_maps`）：
   可买 = `not suspended and not limit_up`｜可卖 = `not suspended and not limit_down`。
3. **S 层超参未在 val 重搜**：照抄 V1 个股线 2026-11-04 在 val 段选定的值
   （lr=0.02 / rounds=500）；算力让给 ETF 层搜索。
4. **换手口径与 V1 不同源**：V2 用「调仓前**漂移**权重」，V1 用「上期**目标**权重」
   ⇒ V2 换手更严 ⇒ 对比偏向 V2 吃亏。
5. **Sharpe 口径与 V1 不同**：V2 用标准口径，V1 是「年化 / 年化波动」的粗口径。
6. 🔴 **调仓节奏 cadence 已于 2026-11-18 锁死 = 20（严格月频），不再进搜索空间**
   （历史留档：`config_v2.REBALANCE_CADENCE_GRID_LEGACY` = {20, 40, 60, 90} 是
   2026-11-17 那轮的搜索空间）⇒ 与 V1 的 16.57× 只能**趋势性**对比
   （换手权重基准仍不同源：V1 = 上期目标权重 / V2 = 调仓前漂移权重）。
7. 🔴 **val 段（2022–2023）样本量不足 + 风格偏科**：484 个交易日 ⇒ 月频仅 ~24 个
   调仓点；且两年是单边熊市 ⇒ 「少动」天然占优 ⇒ **val 段选出的参数普遍水土不服**
   ⇒ 已升级为 **5 折滚动前推**（见上）；但 2024–2026 单盲**已消耗**，
   新候选**不能**回头用它验收（需新盲测窗口或用户显式授权）。
8. 🔴 **换手 ≤4× 在任何配置下都不可达（结构性）**：5 折 OOS 实测冠军换手 **14.10×**
   （`hold_buffer` 2/3/5 ⇒ 14.10 / 13.20 / 11.92×；val 段折叠常量最低 **12.32×**；
