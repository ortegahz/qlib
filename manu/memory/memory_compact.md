## 铁律九条（背下来）

1. **本地优先**：只改本地，改完 `bash manu/tools/sync_to_server.sh` 同步 + md5 双侧比对。
   🔴 **PyCharm `autoUpload=Always` 会反向写入**（GUI 改动直达服务器、本地不变）
   ⇒ 分叉时**先问用户**再定以哪侧为准，**不要**直接用本地覆盖服务器。
2. **上游源码冻结**：不碰 `qlib/`、`examples/`、`tests/`；自研代码放 `manu/`；要 patch 就写成独立 `.patch`。
3. **禁擅自启动重活**：下载 / 训练 / 回测 / 特征重建 / >5 min 任务，必须当轮授权。
4. **算力上服务器**：host 只做编辑与抽检；服务器重活用 `setsid nohup`，**禁止 `nohup &`**。
5. **回测口径必须完整**：区间 / 标的池 / 成本 / 组合约束 / 基准 / 资金 六项缺一不可
