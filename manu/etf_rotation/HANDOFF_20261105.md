## 二之四、🛡️ TA 合规筛选（否决 / 顺延）

**新口径**：TradingAgents 不只是「第二意见」，还承担**合规筛选** ⇒ **审查 → 一票否决 → 顺延**。
🔴 **否决解析只认「真否决」**：条件句（「当前不买；条件买入」）**不算否决**；表格行里带
「条件买入」或目标权重 > 0% 的**不算否决**；「否决权 / 若否决 / 不否决」等反向语义只中和
**它所在的那一句**，不得整句吞掉同句里的真否决。
TA 在决策原文里**点名否决**某只标的时，该标的**从本轮候选里剔除**
（**不是卖出**、目标权重**不写 0**），并从候选池里**顺延**下一个**不同主题**的资产补位
（目标权重沿用被否决者 ⇒ 保持等权口径）；若它本来就在**持仓**里 ⇒ **只剔除候选、不动持仓**
（`ta_screening.held_not_touched = true`）。

**🔴 2026-11-11 审计后的加严与修法（真机实跑暴露）**：
1. **否决解析只认「真否决」**：`条件买入` / `目标权重 > 0%` 的表格行 / `减持但不清仓` / `持（0仓观察）` 之外的一切表述 **都不算否决**；反向语义护栏降到**子句级**（「不得…否决」这种**隔字**否定也要中和 ⇒ 用正则 `否定词 + ≤16 字 + 否决类动词`）。
2. **孤儿持仓（被否决 ∩ 在持仓）**：**保留成一行「维持」**（目标权重 = **当前权重**、目标股数 = 当前股数 ⇒ delta=0 ⇒ 不进挂单）⇒ 市值**仍计入权益口径** ⇒ 权益/现金恒等式自洽、**权益 ≤ 1 − 现金预留比例**。
3. **席位交互**：被否决者若在持仓 ⇒ 席位被「维持」行占住；**顺延补位要过「权益合计 ≤ 1−0.2」闸**，过不了 ⇒ **不补位**并写 `no_substitute_reason` / `cap_skipped`；若账户在该标的上的当前权重本身已超它的席位预算（TA 不许卖 ⇒ 不能减）⇒ 权益必然超配 ⇒ 如实披露 `equity_cap_breach` + `plan["warnings"]`，**不粉饰**。
4. **覆盖闸门**：判 `coverage` 与既有常量 `C.MIN_E_COVERAGE`（0.5）比较（**不是** `coverage_ok` —— 报告候选字典里没有这个键）；缺失 ⇒ fail-closed 判不达标。
5. **顺延池**：每日链 analyze 调用传 `--top-n`（**单一事实源 = `config.ANALYZE_TOP_N` = 100**）⇒ 第 16 名以后的候选可见；`run_pipeline.sh` / `run_gates.sh`（repro 段）**同口径**。
