# manu/memory/archive/ — 历史归档（只增不改）

> **纪律（铁律七）**：本目录**只增不改**。历史内容按年代/专题切分进来，**零字节丢失**。
> 切分归档时必须**逐字节校验**（原文件 md5 与归档后片段拼接结果一致）。

## 怎么读
- **不要线性读归档**。先读 `manu/memory/memory.md` §4 导航表，按 §编号/主题**定点跳转**。
- 需要跨年对比时，再读多个分卷。

## 命名规范
```
<主题>_<YYYYMMDD>.md          # 专题档（如 factor_pool_20261115.md）
<年代>_§<章节号>.md          # 从大档切出的分卷
```
